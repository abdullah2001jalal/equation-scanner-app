# ماسح المعادلات (Equation Scanner)

تطبيق أندرويد يُستخرج النصوص والمعادلات **الرياضية والكيميائية** من الصور (كاميرا/معرض) أو ملفات **PDF** — من طبعات وخط اليد — ويحوّلها إلى ملف **DOCX** جاهز للمشاركة، بطريقة احترافية.

## أبرز الميزات
- OCR ذكي عبر **Gemini** (يدعم خط اليد والطباعة، عربي وإنجليزي).
- تصنيف تلقائي: عناوين، فقرات، قوائم منقطة/مرقّمة، جداول، معادلات مستقلة.
- **معادلات حقيقية داخل Word (OMML/MathJax تعادلي)** — نص قابل للتحرير وليست صور.
- كيمياء بترميز mhchem عبر `\ce{...}` (أرقام سفلية، أعداد التأكسد، أسهم ⟶، توازن ⇌).
- ترتيب داخل الفقرات من اليمين لليسار تلقائيًا للنصوص العربية + تصويب اتجاه Word.
- مشاركة الملف الناتج من أي مكان: واتساب / واتساب Work / بريد / سحابة... أو حفظه فقط.

## التشغيل
1. ثبّت APK (بعد بناء CI) أو شغّله من محرر Flutter.
2. من زر ⚙ الإعدادات: أدخل مفتاح Gemini API خاصتك (من AI Studio) واسم النموذج.
3. اختر مصدرًا: كاميرا أو صور أو PDF، وحرّك تقدم العملية.
4. في شاشة النتيجة اضغط "إنشاء ملف Word ومشاركته" أو "حفظ فقط".

> ملاحظة: بعد فحص مخرج المستند بصريًا، احفظه؛ ويُدرج النص في ملف docx في فقرات حقيقية + معادلات OMML.

## الحصول على مفتاح API
- افتح [AI Studio](https://aistudio.google.com/apikey) وأنشئ API Key، ثم أدخله داخل التطبيق. يُخزَّن مشفّرًا على جهازك فقط ولا يُرسل لأي طرف آخر — يُرسل إلى `generativelanguage.googleapis.com` مع كل طلب.

## بناء APK عبر GitHub Actions
- يُشغَّل تلقائيًا مع كل تدفق (push) إلى `main`: تحليل → اختبارات → `flutter build apk --release` → رفع Artifact + **Release** جديد (`build-<رقم>`) بتنزيل مباشر بدون حساب.
- يدويًا: قائمة Actions → Build APK → Run workflow.
- بديل محلي: `flutter build apk --release` بعد `flutter pub get` (يخرج في `build/app/outputs/flutter-apk/`).

## إخراج الملف الناتج
من شاشة النتيجة → "احفظ فقط" أو "مشاركة". الملف يُحفظ في مجلد مستندات التطبيق.

## الخصوصية
- الصور/الصفحات تُرسل مباشرة إلى واجهة Gemini API فقط (بلا خوادم وسيطة)، ولا يُخزَّن أي مفتاح API داخل المستودع.
